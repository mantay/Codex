# Codex

Simple Flask panel for managing Yandex Market digital orders.

## Setup

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Copy `.env.example` to `.env` and adjust values if needed.

3. Run the web app:
   ```bash
   python app.py
   ```

The app lists current orders and lets you submit digital codes for each order.
